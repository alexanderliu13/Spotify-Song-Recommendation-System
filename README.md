# Spotify Song Recommendation System
This recommendation system leverages the Spotify API to give you personalized song recommendations based on similarity metrics and song popularity.

My initial inspiration behind this project was utilizing my passion for software in order to make my hobbies even more enjoyable. I'm an avid music listener (I was in the top 4% of all Spotify users for most music listened to last year!), but this means that I always have to be on the lookout for new music. Finding new music was always a frustrating process for me because I found that Spotify's built in song recommendations were usually too mainstream for my taste, meaning that I was already familiar with those songs! Knowing this, I wanted to build a recommendation system that found songs similar to a particular song that I enjoyed, but also gave me the option to adjust the popularity level of the recommendations so I could find songs that weren't too mainstream or too underground for my taste. With that, this app was born. 
Through this process, I've picked up valuable skills in machine learning and data analysis including preprocessing datasets and implementing similarity metrics utilizing machine learning libraries. I've also gained hands-on experience in many Python libraries such as pandas, numpy, and scikit-learn libaries.

## Using your own credentials
You will need to register your app and get your own credentials from the [Spotify for Developers Dashboard](https://developer.spotify.com/dashboard).
## Features
* Accepts user input for song popularity and combines this with song similarity to generate 5 song recommendations
* Provides recommendation scores for each song on a 100-point scale
* Provides Spotify URLs and Spotify Cover Arts for each song
